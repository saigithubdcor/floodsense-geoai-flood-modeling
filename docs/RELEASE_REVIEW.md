# Release review notes

**Source provenance:** 17 original checkpoint-tracked file hashes validated and preserved during the R3 export. No scientific models, model weights, raw rainfall/terrain data, or service-side datasets are included here.

**Local routes:** Some HTML and Python source files reference 127.0.0.1 development endpoints. These are local placeholders for the source application architecture, not accessible public services or API keys.

**Permissions and attribution:** This repository is intended to publish authorized work with collaborative credits. MapLibre's third-party license is included. Other map/tile hosting and dataset rights are separate.

**Before public deployment:** isolate API configuration, document dependencies, replace local environment assumptions, restore genuine backend services, test map/asset/replay interactions and avoid unsupported flood warning claims.
